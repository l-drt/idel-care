# Assets IDEL Care

Ajouter les fichiers suivants pour le build Expo :

- **icon.png** — icône de l’app (1024×1024 recommandé)
- **splash.png** — écran de démarrage
- **adaptive-icon.png** — icône Android adaptive (1024×1024)

Vous pouvez générer des placeholders ou utiliser les assets par défaut d’Expo en attendant.
